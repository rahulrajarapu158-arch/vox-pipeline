# Vox Pipeline

Video generation and animation pipeline using AI models.

## Contents

- **LTX_I2V_Colab_Notebook.ipynb** — LTX image-to-video generation notebook
- **LTX_I2V_Colab_Notebook.py** — Python version of the LTX notebook
- **SVD_Colab_Notebook.py** — Stable Video Diffusion notebook
- **README_workflow.txt** — Workflow documentation

## Setup

1. Upload the notebooks to Google Colab
2. Install dependencies as noted in each notebook
3. Run cells in order

## Requirements

- Google Colab (GPU recommended)
- Python 3.10+
- PyTorch, Diffusers, Transformers
